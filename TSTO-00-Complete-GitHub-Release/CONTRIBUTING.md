# Contributing to TSTO

TSTO/00 is an experimental draft. Implementation evidence is more useful than abstract feature requests.

Useful contributions include independent validation, incompatible interpretations, real-workflow Profiles, Core ambiguity reports, privacy or security analysis, and deterministic test vectors.

Use these issue-title prefixes where practical:

- `[interop]` cross-implementation behavior;
- `[schema]` structural validation;
- `[semantics]` normative meaning;
- `[binding]` JEP-TSTO event behavior;
- `[profile]` domain Profile proposal;
- `[security]` non-sensitive security discussion; and
- `[editorial]` wording or formatting.

Do not add execution, responsibility, price, payment, or settlement fields to TSTO Core. State the interoperability failure addressed by a proposed change and include examples plus expected behavior when possible. Frozen Draft 00 semantics require a new revision.

By contributing, you represent that you have the right to submit the material and agree that accepted contributions are published under CC BY 4.0. Contributions must disclose known third-party rights and relevant patent claims.

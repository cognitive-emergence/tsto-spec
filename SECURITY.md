# Security Policy

TSTO/00 and JEP-TSTO Binding/00 are experimental specifications, not complete security, identity, authorization, or settlement protocols.

Do not place vulnerabilities, credentials, production evidence, personal data, signing keys, or commercially sensitive records in public Issues. Use the repository's private security advisory feature for sensitive reports.

A report should identify the affected version, Profile or Policy, attack condition, expected property, and whether the issue affects Schema validation, semantic verification, canonicalization, evidence resolution, JEP signature coverage, digest-domain separation, or Binding behavior.

No production deployment should rely on the illustrative unsigned JEP examples.

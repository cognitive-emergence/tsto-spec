# Conformity publication

Normative publication currently lives only in this Git repository. No humanjudgment.org hosting is asserted. Namespace URIs are stable identifiers, not required network resources. All verification can run offline with independently supplied issuer trust.

- [Immutable 1.0 foundation](1.0/README.md)
- [Record and Report 1.1 limitations supplement](1.1/README.md)
- [Conformity 1.2](1.2/README.md): Record 1.2 (delegation scope `VERIFY`), Verification 1.2 (Report 1.2, reason catalog and the normative verification procedure) and package supplement 1.2 (anchoring evidence)
- [Conformity 1 conformance suite](conformance/conformity-1/README.md): signed vectors for 1.0, 1.1 and 1.2 and a runner for any verifier

[SHA256SUMS.txt](SHA256SUMS.txt) lists the 1.0 and 1.1 files as published on 2026-10-25 (this README has changed since); [1.2/SHA256SUMS.txt](1.2/SHA256SUMS.txt) and [conformance/conformity-1/SHA256SUMS.txt](conformance/conformity-1/SHA256SUMS.txt) list the later files.

Package, Summary and Status remain the three portable artifacts. This publication does not modify TSTO/00 or JEP Core. These are experimental specifications, not a claim of formal standards-body approval.
